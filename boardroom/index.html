What the research found

Constraint: GO (conditional we already meet)
Vector-observation headless builds need no GPU, display, Xvfb, or runtime license. Our env is vector, so we're on the easy path. Visual/camera obs would force Xvfb — we avoid that.
Stack: SB3 + PettingZoo + bespoke league
Stable-Baselines3 2.9 (PPO) + PettingZoo, with our own PFSP/ELO self-play league (our 2021 scripts, modernized). Ray Tune PBT is hyperparameter tuning, not self-play — not a substitute.
GCP: crawl → managed Ray
Containerize → Artifact Registry → single-GPU job → managed Ray on Vertex AI later. Cheap CPU Spot sim-workers + one GPU learner. GPU quota starts at 0 — request early.
