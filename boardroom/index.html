The finding that de-risks it

✓
Your pretrained CNN drops straight into current SB3.
SB3 2.9's NatureCNN is layer-for-layer identical to your 2021 net, same .cnn/.linear submodules — so 1M_pretrained_cnn.pth / _linear.pth load with no surgery. It was trained as an "inverse renderer" (grid → game state), so it's a near-ideal starting representation. We freeze it for the first run so PPO only has to learn the policy.

The plan

  1. Prereqs
    Add the RL stack (torch 2.9 CUDA + SB3 2.9 + gymnasium 1.3, version-verified) and fix a confirmed live blocker: trailing commas in a level JSON crash the pixel env on construction.
  2. Env → gymnasium
    Port TankEnv into the tank_twin package (5-tuple step with a proper terminated/truncated split — a correctness upgrade for PPO; seeded reset), splitting out the socket I/O, reward, and arena loading. Wire contract + grid stay byte-identical → RL seam untouched. Validated against a fake socket (no live Unity needed).
  3. Pretrained-CNN extractor
    Load your weights into SB3's feature extractor; frozen by default, with a flag to unfreeze and fine-tune later.
  4. Trainer + eval
    A train_local entry point — PPO(CnnPolicy) + the pretrained extractor + a random opponent — with a win-rate-vs-random eval callback and TensorBoard curves.
  5. Standards + tests
    Migrate the training code into the package; unit-test the pure pieces (reward, grid transform, extractor-load wiring, the gymnasium contract via fake socket) + one e2e that runs the pipeline and round-trips a checkpoint (never asserts convergence).
  6. The M1 smoke (the bar)
    ~200–500k steps on your GPU; demonstrate win-rate climbing ~50% → ~70%+ and a rising reward curve. That validates M1.
How it's gated
Same machine as M0 — scope → build → code-reviewer → verification-lead → merge — now with the regression test net catching breakage. RL seam stays off-limits (Python side only; wire contract unchanged).
What validates "it learns"
Win-rate vs a random opponent rising from ~50% toward ~70%+ (the load-bearing metric), plus ep_rew_mean trending up. Shown on TensorBoard from a single-seed local GPU run.
